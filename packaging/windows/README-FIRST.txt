STEADY FOR WINDOWS

1. Extract the complete Steady-Windows folder to a location you own.
2. Double-click Steady.exe to launch the application.
3. Optional: right-click Create-Shortcut.ps1 and choose Run with PowerShell
   to create a desktop shortcut.

Do not move Steady.exe out of this folder: the _internal directory contains
required runtime files.

Your planner database and backups are stored separately in your Windows user
application-data directory. Updating the application does not replace them.
